# RegimeBadge
States the current macro regime. Four labels only: Goldilocks, Overheating, Stagflation, Recession Risk.

```jsx
<RegimeBadge label="Overheating" confidence={0.52} />
```

- Fill is always the muted translucent treatment — never a solid colour block.
- `size="sm"` inside table rows and card headers; default in page headers.
