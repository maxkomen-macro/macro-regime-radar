# Tag
Small mono chip for alert levels, conviction, percentile ranks, and source attribution.

```jsx
<Tag tone="warn">Watch</Tag>
<Tag tone="research" size="md">Perplexity</Tag>
```

- Tones map to meaning, not decoration: pos = clear/risk-on, warn = watch, neg = triggered, research = Perplexity-sourced, accent = informational.
- Keep to one or two words. Uppercase by default.
