# ReadThrough
Long-form generated commentary — the "Current read-through" panel.

```jsx
<ReadThrough paragraphs={[p1, p2]} footerLabel="Playbook bias" footer="Prefer real assets…" />
```

- Two to four paragraphs, 13px, 1.55 line-height. The accent rail marks it as model output rather than measured data.
- The footer is a single directional line; keep it to one sentence.
